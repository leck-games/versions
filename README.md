# Sine Rally · Version Manager

**https://leck-games.github.io/versions/**

Every Sine Rally build, frozen and playable. Each version has a description, its date (Vienna time), a commit link and a screenshot, and every project has a collapsible changelog listing all of its commits.

| Project | Folder | Repos |
|---|---|---|
| Sine Rally (the game, incl. **Sine Rally V0.1**) | `sinerally/` | leck-games/sinerally (classic, frozen) → leck-games/sinerally-ui |
| Sine Rally Route (**Sine Rally Route V0.1**) | `route/` | leck-games/sinerally-route (fork of sinerally-ui; changelog from the fork point via `"since"` in milestones.json) |
| Sine Rally Engine | `engine/` | leck-games/sinerally-engine |
| Engine Sim | `enginesim/` | leck-games/engine-sim |
| Physics Lab | `physics/` | leck-games/sinerally-physics |
| Terrain | `terrain/` | leck-games/sinerally-terrain |

Builds before V0.1 are labelled `pre-0.1 build N`. The other projects use `0.0.N`.

## Layout

```
index.html, app.js        the site (no build step); renders versions.json
versions.json             GENERATED by tools/build-versions.py; do not edit by hand
<project>/<slug>/         frozen snapshot (git archive of that commit), played at /versions/<project>/<slug>/
thumbs/<project>-<slug>.jpg
tools/milestones.json     SOURCE OF TRUTH: projects, versions, labels, descriptions
tools/build-versions.py   exports missing snapshots + writes versions.json (changelogs from git log)
tools/snapshot-test.cjs   headless smoke test of every snapshot (+ --thumbs screenshots) -> tools/smoke.json
tools/site-shots.cjs      headless UI check of the site + screenshots into shots/ (gitignored)
```

## Rules

* **Snapshots never change.** `build-versions.py` only exports folders that don't exist yet. Don't edit a snapshot. If one is broken, publish a new version.
* Snapshots use relative paths and the repo's own vendored three.js, so each folder runs on its own.
* `build-versions.py` adds a small shim at the top of every snapshot's `<head>`:
  * **localStorage is namespaced** as `vm:<project>/<slug>:`. All builds share the `leck-games.github.io` origin, so without this an old build could read or overwrite a newer build's saves.
  * **Service worker registration is disabled**, so a frozen copy can't take over a scope.

## Add a version

The local clones of the project repos must be up to date (paths are in `milestones.json`).

1. Add an entry to that project's `versions` list in `tools/milestones.json`, in chronological order:
   ```json
   {"slug": "v0.2", "label": "V0.2", "repo": "leck-games/sinerally-ui", "commit": "abc1234",
    "title": "Sine Rally V0.2", "desc": "What is new, in one or two sentences.",
    "badges": ["V0.2"], "release": "https://github.com/leck-games/sinerally-ui/releases/tag/v0.2"}
   ```
   The last entry of each project automatically gets the `latest` badge.
2. `python3 tools/build-versions.py` exports `sinerally/v0.2/` and regenerates `versions.json`.
3. Serve the folder (`python3 -m http.server 18950`), then run `node tools/snapshot-test.cjs --thumbs --only sinerally/v0.2` to smoke test it and save a screenshot.
4. Convert the screenshot to JPG (480×222) into `thumbs/sinerally-v0.2.jpg`, delete the PNG, then run `python3 tools/build-versions.py --check` to rebuild `versions.json` with the thumb and test result.
5. Optionally run `node tools/site-shots.cjs` to check the site.
6. Commit and push. GitHub Pages deploys from `main` /.

Thumb conversion one-liner:
```
python3 -c "from PIL import Image;import glob,os;[ (Image.open(f).convert('RGB').resize((480,222),Image.LANCZOS).save(f[:-4]+'.jpg',quality=72,optimize=True),os.remove(f)) for f in glob.glob('thumbs/*.png')]"
```
